# CimaNow Android

A simple Android WebView wrapper for https://cimanow.cc/.

## Build
Push to `main` or manually run the **Build CimaNow APK** workflow in GitHub Actions. Download the `CimaNow-debug-apk` artifact from a successful run.

This wrapper loads the website as served by the site. It does not remove ads served by the website or bypass site access restrictions. Website compatibility and media playback depend on the site's policies and Android WebView.
